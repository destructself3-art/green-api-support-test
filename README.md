HTML-страница для позиции «Специалист технической поддержки 2 линии». Автор: Мухамеджанов Рустам.

## Соответствие заданию

| Требование | Реализация |
| --- | --- |
| getSettings | GET, вывод текущих настроек |
| getStateInstance | GET, вывод состояния и пояснение |
| sendMessage | POST с chatId и message |
| sendFileByUrl | POST с chatId, urlFile, fileName и необязательной caption |
| idInstance и ApiTokenInstance | Поля подключения; токен скрыт по умолчанию |
| Ответ в отдельном поле только для чтения | textarea с readonly, JSON с отступами |
| Макет из PDF | Подключение и методы слева, большая панель ответа справа |
| Публичный код и HTML-страница | GitHub + GitHub Pages |
| Короткое видео | Папка presentation и отдельная страница материалов |

## Запуск

Никакие зависимости для приложения не нужны. HTML/CSS и JavaScript (ES modules), запросы через Fetch API.

```sh
npm start
# http://127.0.0.1:4173
npm test
```

Нужен Node.js 20 или новее. Также можно использовать любой статический HTTP-сервер. Запуск через file:// не рекомендуется из-за ограничений модулей браузера.

Дополнительно можно повторить браузерные проверки: установите Playwright (`npm install --no-save playwright` и `npx playwright install chromium`), оставьте `npm start` работающим и в другом терминале запустите `node tests/browser.mjs`. Флаг `--record` записывает видео в test-results. В Windows при установленном Edge можно задать `BROWSER_CHANNEL=msedge`. Снимки пишутся в presentation; это тестовые данные.

## Проверка с настоящим инстансом

1. В https://console.green-api.com/ создайте инстанс WhatsApp на тарифе «Разработчик», если он доступен аккаунту. Оплачивать тариф для этой страницы не требуется.
2. Подключите свой WhatsApp: в кабинете получите QR-код, на телефоне откройте «Связанные устройства» и отсканируйте его.
3. Откройте опубликованную страницу. Введите idInstance, ApiTokenInstance; в разделе «Адрес API» укажите **apiUrl из кабинета**, если он отличается от общего хоста.
4. Нажмите getSettings — справа должны появиться настоящие настройки.
5. Нажмите getStateInstance — ожидается `{"stateInstance":"authorized"}`. Если получен notAuthorized, завершите подключение WhatsApp.
6. Введите свой номер либо номер согласованного получателя с кодом страны (например, `77771234567`), напишите тестовый текст и нажмите sendMessage.
7. Проверьте idMessage в ответе и фактическое получение текста в WhatsApp.
8. Для файла используйте прямую публичную ссылку, например опубликованный скриншот: `https://destructself3-art.github.io/green-api-support-test/presentation/desktop.png`. Заполните получателя, нажмите sendFileByUrl и проверьте файл в WhatsApp.

**idMessage подтверждает приём в очередь, а не доставку.** При таймауте или сетевой ошибке не повторяйте отправку, пока не проверите результат: исходный запрос мог быть обработан сервером.

## Защита и обработка ошибок

- Токен вводится пользователем и не хранится в localStorage, sessionStorage, cookie или исходниках. Запрос идёт прямо на официальный HTTPS-хост GREEN-API; собственного сервера для токенов нет.
- Хост проверяется по списку официальных доменов. Чужие домены, HTTP, логин/пароль, нестандартные порты и путь отклоняются до вызова.
- Для API отключены cache, credentials и referrer; перенаправления отклоняются. Токен из URL запроса неизбежно виден владельцу браузера в DevTools — это формат самого GREEN-API.
- Токен маскируется, если сервер повторил его в теле ответа. JSON или текст выводится как значение textarea, без HTML-интерпретации.
- Одновременно выполняется один запрос. Все четыре кнопки блокируются на время ожидания; повторных автоматических отправок нет.
- Таймаут 45 секунд. Для 400, 401/403, 404, 429/466, 5xx и сетевых ошибок выводится пояснение. Исходное тело HTTP-ошибки сохраняется в поле ответа.
- Номера нормализуются в `@c.us`. Поддерживаются личные, групповые и lid chatId. Имя файла определяется из URL, при необходимости задаётся явно.

Публичная тестовая страница не заменяет корпоративный клиент с управлением доступом. Токен и личные настройки не следует включать в видео или публичные скриншоты.
