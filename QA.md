**24 проверки логики, 20 браузерных проверок — успешно.** Проверен Chromium через установленный Microsoft Edge в отдельной тестовой сессии. API-запросы браузерных тестов перехвачены Playwright, внешняя отправка не выполнялась.

Визуально просмотрены скриншоты основной, мобильной страницы и HTTP-ошибки. Макет сохраняет порядок полей и методов, левую колонку управления и отдельную правую панель ответа. На мобильном экране колонки идут последовательно.

## Проверка публикации

GitHub Pages успешно опубликован через GitHub Actions. Основная страница, страница презентации и все их ресурсы доступны по HTTPS. У 11 опубликованных файлов подтверждены HTTP 200 и совпадение SHA-256 с локальной проверенной версией. Видео H.264 MP4 длительностью 30,52 секунды (1280 × 1600) воспроизводится в браузере. На публичной странице повторно проверены загрузка JavaScript и валидация пустого подключения; ошибок выполнения нет.

## Границы проверки

Действующий инстанс GREEN-API отсутствует. Не подтверждены реальная авторизация, getSettings/getStateInstance для настоящего аккаунта, доставка текста и файла в WhatsApp. Видео и скриншот ошибки используют тестовые ответы, что явно обозначено в презентации и кадрах видео.

Пробные OPTIONS-запросы к официальным API-хостам с заведомо недействительным idInstance получили HTTP 403 без CORS-заголовков. Это **не подтверждает и не опровергает** CORS для действующего инстанса. Финальную интеграцию нужно проверить с apiUrl, idInstance и токеном из кабинета. При браузерной сетевой ошибке страница сообщает о возможном CORS, не скрывая ограничение.

Успешный ответ с idMessage означает принятие запроса в очередь, а не доказательство доставки. Для окончательной приёмки необходимо проверить сообщение и файл в WhatsApp получателя по инструкции в README.

## Повторяемость

- `npm test`: тесты контракта и ошибок без обращения к реальному API.
- `node tests/browser.mjs`: проверка страницы через Playwright, с локальным сервером `npm start`.
- `node tests/browser.mjs --record`: те же проверки и запись демонстрации.
- В GitHub Actions проверки логики обязательны перед публикацией.

Резюме, письмо работодателю и реальные данные подключения не входят в репозиторий и опубликованный сайт.
